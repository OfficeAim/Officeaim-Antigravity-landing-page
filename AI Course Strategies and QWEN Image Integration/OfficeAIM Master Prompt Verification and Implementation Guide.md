# OfficeAIM Master Prompt Verification and Implementation Guide

This document outlines the steps to verify the newly compiled OfficeAIM Master ChatGPT Prompt and provides guidance for its implementation, ensuring all 8 AI agents are integrated and the evergreen content strategy is properly adopted.

## 1. Verification Tasks

To ensure the Master Prompt is functioning as intended, perform the following verification tasks within a new ChatGPT project:

### Task 1.1: Agent Recognition and Role Confirmation

**Objective:** Verify that the AI Project Manager recognizes all 8 agents and their respective roles, including the newly added Behavioral Psychologist & UX Strategist.

**Action:**
1. Start a new ChatGPT conversation and paste the complete Master Prompt.
2. After the AI Project Manager confirms understanding, ask the following question:
   "AI Project Manager, please list all the AI agents currently on the OfficeAIM team and briefly describe their primary role (1-2 sentences each)."

**Expected Outcome:** The AI Project Manager should accurately list all 8 agents (Course Creator, AI Prompter, Marketing Pro, Community Builder, Quality Checker, SEO Master, Business Strategist, and Behavioral Psychologist & UX Strategist) and provide a concise summary of each agent's function.

### Task 1.2: Evergreen Content Strategy Integration

**Objective:** Confirm that the AI Project Manager and relevant agents (e.g., Marketing Pro, Course Creator, SEO Master) understand and apply the evergreen content strategy.

**Action:**
1. Following Task 1.1, ask the AI Project Manager:
   "AI Project Manager, how will the evergreen content strategy influence the content creation process for OfficeAIM, particularly for the Course Creator and Marketing Pro agents?"

**Expected Outcome:** The AI Project Manager should explain how the evergreen content strategy will guide content development, emphasizing focus on fundamental, long-lasting AI applications and user actions, and how this will reduce the need for frequent updates. It should also mention how this strategy will be communicated to and adopted by the relevant agents.

### Task 1.3: Inter-Agent Communication and Collaboration

**Objective:** Verify that agents can communicate and collaborate as instructed in the Master Prompt.

**Action:**
1. Ask the AI Project Manager to initiate a collaborative task:
   "AI Project Manager, please instruct the Course Creator to outline a module for 'The AI Productivity Sprint' focusing on 'AI-Powered Email Management'. Then, ask the Behavioral Psychologist & UX Strategist to review this outline and provide recommendations to enhance learner engagement and reduce anxiety, specifically for administrative assistants."

**Expected Outcome:** The AI Project Manager should first provide an outline from the Course Creator. Subsequently, the Behavioral Psychologist & UX Strategist should offer specific, psychologically-informed recommendations for the module, demonstrating inter-agent communication and application of their specialized knowledge.

### Task 1.4: New Agent's Specific Contribution

**Objective:** Confirm the Behavioral Psychologist & UX Strategist agent's ability to provide specific, actionable insights based on its defined role.

**Action:**
1. Ask the AI Project Manager to direct a question specifically to the new agent:
   "Behavioral Psychologist & UX Strategist, what are three key psychological barriers white-collar professionals face when adopting new AI tools, and how can OfficeAIM's course design specifically address these to improve course completion rates?"

**Expected Outcome:** The Behavioral Psychologist & UX Strategist should identify three relevant psychological barriers and propose concrete course design strategies to mitigate them, linking directly to improving completion rates as per its prompt.

## 2. Implementation Guide

Follow these steps to effectively implement the new Master Prompt:

1.  **Prepare ChatGPT Environment:** Open a new ChatGPT conversation. Ensure it's a clean slate to avoid any previous context interfering with the new Master Prompt.
2.  **Paste Master Prompt:** Copy the entire content of the `/home/ubuntu/officeaim_master_chatgpt_prompt_final.txt` file and paste it as the very first input into the new ChatGPT conversation. This establishes the AI Project Manager and all its agents.
3.  **Initial Confirmation:** Wait for the AI Project Manager to acknowledge its understanding of the setup and all agent roles. It should typically ask for the first task.
4.  **Execute Verification Tasks:** Systematically go through each of the verification tasks outlined in Section 1 of this document. Observe the responses carefully to ensure they align with the expected outcomes.
5.  **Iterate and Refine (if necessary):** If any verification task yields unexpected results, review the relevant agent's prompt within the master file and consider minor adjustments. Repeat the verification process with the revised prompt.
6.  **Begin New Projects:** Once verified, you can confidently use this Master Prompt for all future OfficeAIM-related ChatGPT projects. Always start a new conversation with the full Master Prompt to ensure consistent agent behavior.
