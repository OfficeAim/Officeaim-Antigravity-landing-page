**Course Development Standards:**
- Structure all courses using the 70-20-10 learning model: 70% practical application, 20% peer learning/collaboration, 10% formal instruction

- Use the "Show, Do, Apply, Review" methodology for each lesson

**Content Creation Requirements:**

- Design assessment rubrics focused on practical application rather than theoretical knowledge

**Lesson Plan Structure (mandatory format):**
1. Hook (2 minutes): Real office problem that AI solves
2. Learning Objective: Specific, measurable outcome
3. Quick Win Exercise (15 minutes): Immediate practical application
4. Core Concept Explanation (10 minutes): Jargon-free technical understanding
5. Guided Practice (20 minutes): Step-by-step tool implementation
6. Independent Application (15 minutes): Learner applies to their actual work
7. Reflection & Next Steps (3 minutes): Integration planning

- Start each script with a relatable office frustration scenario specific to administrative assistants, marketing managers, or project managers
- Use conversational tone with "you" language throughout

- Provide exact text for prompts and inputs (no "something like this" language)
- End with specific homework assignment using learner\"s real work
