# Skill: Visual Layer

## Descripción
Automatiza la generación de prompts de imagen y la creación de activos visuales para el "AI Lab" de OfficeAIM, asegurando una estética de lujo y coherencia visual con el branding de Antigravity.

## Cuándo Activar
Gatillos: "genera los visuales para el módulo X", "crea un prompt de imagen para esta lección", "necesito un fondo premium para el Dashboard".

## Checklist de Calidad OfficeAIM
- [ ] **Estética Premium**: ¿Las imágenes proyectan tecnología de élite (orbes, cristales, partículas, gradientes cian/oscuro)?
- [ ] **Coherencia de Marca**: ¿El prompt incluye descriptores de iluminación volumétrica y estilo cinematográfico?
- [ ] **Branding**: Alineado con el manual de marca `#05070A` (Fondo) y `#22D3EE` (Acento).
- [ ] **Format Compatibility**: ¿Los prompts están optimizados para modelos de generación de imagen de alta resolución?

## Protocolo E.T.A.P.A. (Ejecución Determinista)
1.  **E**ntender: Mapear el concepto central de la lección (ej. "Chain of Thought" -> un hilo de luz conectando nodos).
2.  **T**rabajar: Construir un prompt descriptivo siguiendo el estilo "Luxury Future Tech".
3.  **A**nalizar: Verificar que los elementos visuales no sean distractores y refuercen psicológicamente el aprendizaje.
4.  **P**robar: Generar una vista previa conceptual (usando la herramienta generate_image).
5.  **A**plicar: Guardar la ruta de la imagen generada en la base de datos (vía SQL Seed).

## Formato de Salida
Prompts de imagen o Archivos de imagen (.webp/.png).

## Style Keywords para Prompts
- "Luxury Tech Aesthetic", "Volumetric Cyan Lighting", "Deep Space Black Background", "Hyper-detailed glass elements", "Orbits of energy", "Cinematic composition".
