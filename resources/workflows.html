How to import these pipelines into n8n in 15 seconds

Every workflow in this vault is a standard n8n JSON schema that works in both n8n Cloud and self-hosted Docker instances:

1. Copy JSON or download file

Click "Copy JSON 📋" on any card to copy the raw workflow schema to your clipboard, or click "Download .json ⬇️" to save the file locally.

2. Paste directly on your n8n canvas

Open your n8n workflow editor and press Cmd+V (Mac) or Ctrl+V (Windows) directly on the canvas, or select Import from File in the top-right menu.

3. Bind your API credentials

Open the highlighted trigger or AI nodes to select your own API keys (Gemini, OpenAI, Supabase, Telegram, or SMTP) and toggle the workflow active.
