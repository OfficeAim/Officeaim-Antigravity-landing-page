🏛️ Architectural foundation · The restaurant metaphor

The problem with code without architecture

Asking an AI code generator (Lovable, v0, Cursor, Bolt) to "build my app" without system architecture is like opening a restaurant with only tables and chairs. For an AI builder to deliver a working product on the very first turn, you must define how these 4 parts interact before requesting code:

✓ 4-pillar first-turn standard
🍽️ 1. The dining room

Interface & UI shell

What the user sees and touches. Responsive menus, interactive cards, debounced search, and 1-click copy feedback (<100ms).

Stack: React + Tailwind CSS
👨‍🍳 2. The kitchen

Server & business logic

Processes business rules, assigns roles (1st user = admin, others = student), and keeps API secrets strictly out of client code.

Stack: Edge Functions & Triggers
🗄️ 3. The pantry

Database & RLS vault

Persistent relational storage designed around query patterns, pre-loaded with seed data, and locked with Row-Level Security (RLS) from day 1.

Stack: Supabase PostgreSQL 16
🛵 4. The couriers

External webhooks & queues

Any slow task (>1s) is delegated to background couriers: Stripe payments, n8n/Make webhooks, WhatsApp routing, and Brevo emails.

Stack: n8n / Make / Stripe / Brevo
